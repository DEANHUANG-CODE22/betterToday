# NowORNever 界面规范

> 内部文档。给改界面的人用，不是对外材料。
>
> 更新：2026-11-13　判断只涂本档的词，数据停在哪天写在页顶，记录列表时长写成「49 分」。2026-11-10　圆角收到 8。能点的一块和当天的结论才成面，其余用细线。结算标题用正文色。token 在 `mobile/src/components/theme.ts`
>
> 规则和计划不在这里。判断怎么得出见 [PRD.md](PRD.md) §6，栏目怎么分见 [PRD.md](PRD.md) §4。

一句话：**一块内容一个主角。** 起床那一屏的主角是昨夜。训练前，「运动」的主角是剂量。练完之后，主角换成这一次。

## 不采用的方向

2026-11-05 对着现成界面重排过一次，这两条当时就被丢掉，不要再捡回来：

- 运动类落地页：大色块、游戏化、勋章、连续打卡。这个产品成功的样子是少打开，不是多停留。
- 养生配色和衬线标题。深底和橙色已经是这套界面的颜色，不另换一套字体（也不加字体包）。

## 颜色

| Token | 值 | 用在哪 |
| --- | --- | --- |
| `bg` | `#0E1116` | 页面底 |
| `card` / `border` | `#171B22` / `#262D3A` | 卡片和细线。卡片边框用这条，不用判断色把整张卡框起来 |
| `text` / `sub` | `#EEF1F5` / `#8A93A3` | 正文 / 次要。判断整句用正文色 |
| `accent` | `#FF6B2C` | 当前 Tab、当前筛选项、选中的按钮。负荷数字不用它 |
| `good` / `fair` / `poor` / `blue` | `#3DDC97` / `#F5C24C` / `#FF5C6C` / `#5AA9FF` | 判断里只涂这一档自己的那个词：强度 `good`、有氧 `blue`、休息 `poor`（回归期 `fair`，标题里没有对应的词）。按 `kind` 找词，被否定的词不上色，「今天别上强度」整句正文色。另外涂方向确实好坏的箭头 |

方向色：

- 静息心率升高用暖色。这个方向对身体不好。
- 负荷比偏低用中性色（`TrendBadge` 的 `neutral`）。偏低是信息，不是故障。偏高仍用暖色。
- 没有恢复分、没有睡眠，不要用绿色卡片去说「可以上强度」。许可语等 §5.3 用本人 60 天分布校准之后，只出现在运动页的建议里。

图标用 `icons.tsx` 里的线框 SVG，线宽保持一套。不用 emoji 当图标。

## 字和间距

- 判断用 `font.metric`（22）。把握用 `font.subhead`（13），和判断第一行同一条基线（`alignItems: 'baseline'`，不要再加 `marginTop`）。
- 承载信息的字不小于 `font.footnote`（12）。`micro` / `caption` 只给非信息装饰。
- 间距用 `space`：4 / 8 / 12 / 16 / 24。触控热区 `touch` = 48。按下用透明度，不改布局。
- 圆角 `radius` = 8。环仍是圆的。
- 能点的一块，和当天的结论（建议或结算），才单独成面。本周和当月这两张图也成面，因为当月能点、两张是一对。其余用顶上的细线和空隙分开。卡里不再套一块带底色的小块，数字直接落在面上。
- 结算那句用正文色。强调色只给当前 Tab、当前筛选项、选中的按钮。

## 睡眠与恢复

默认打开这里。第一眼是三个环：睡眠时长、夜间 HRV、最新恢复。环下面才是分期、区间、档位。

- 三个环各走各的日期，日期写在环的名字下面。缺的环里写「没有」，不点进去，也不合成「昨夜」。
- 睡眠环用睡眠蓝。有评分才按评分画弧，没有评分只留轨道。
- 夜间 HRV 有手表区间时，区间是环上的一段色带，当晚的值是一个点。在区间里数字用正文色，出了区间点和数字用黄。环上和环下都不写「高于区间」这类话。没有区间时只留轨道和数字，不画满。
- 恢复没有手表判断时只留轨道，不画满。有判断才用绿 / 黄 / 红把弧画上。对不上的词不上色。不用固定百分比给恢复分上色。
- 环下面的卡片不重复环里的数字，也不再写一遍日期。睡眠卡留下入睡到起床的时段和分期。能点的环，名字旁边用和指标行同一支线框箭头。没有这些内容就不放卡片。
- 手表给了恢复分，才显示数字，文案只写「手表给出的恢复分」。
- 这一页不下今天练不练的判决。许可语等 §5.3 校准，校准前也不出现在这里。

## 日常健康

按日期看。默认今天，不记住上次翻到哪。日期一律写「11 月 8 日」。今天的标题仍是「今天」，下面用这套日期；其他日子标题是这套日期，下面是星期。已经是今天时，右侧 › 更淡，点一下在日期下面写「已经是今天」。

有当天压力曲线时，第一张卡是压力，数字比下面的指标行更大。上面是这一天的日均，下面是每 5 分钟一根线，纵轴固定 0–100，缺的时段断开。线的末端有一个圆点，按住可以换时刻，不另写提示。点标题进原来的多日趋势。没有曲线的日子，压力仍是数字行，数字下写「0–100」。没连接时的模拟数据也带这根线。

步数没有按小时的数据。压力采样里的心率目前整段是 0，没有单独的日间心率曲线。这两项保持数字行，不在这一页画 7 日小图。

有数的项排成左标签、右数字的一行，行尾是线框箭头，点进去看趋势。血氧和呼吸通常只有一次，数字用次要色，并写「只有这一次」，没有 ›。

空的日期仍是一句「没有步数、静息心率和压力」。这三项里缺了的，在有数的日子下面补一句。

静息心率这一行可以写 28 日基线。升高用暖色。步数、消耗没有对照。压力没有和自己的基线比，只标这把尺子是 0–100。

静息心率也会出现在建议依据里。那边只回答今天缺不缺、偏不偏。按天翻在这一页。

## 趋势

点一个环或一行，只看这一个指标。

- 上面是选中这一天的数字和日期，然后一句「近 7 日均 …，你的 28 日基线是 …」。只写高低，不下该练该歇。按住图可以换一天，数字跟着走。
- 7 天 / 30 天。睡眠时长可以到 90 天。少于 4 个点不画图，写「天数还不够」。缺的日期断开，不补 0。步数、楼层、运动分钟、活动消耗用柱，纵轴下沿是 0，图例是一截柱。心率、HRV 用线。压力也用线，纵轴固定 0–100，不把几天之间的小起伏拉满。睡眠时长也用线，纵轴至少拉开 4 小时，避免一小段起伏铺满整张图。选中的那一天是一个圆点，不另写「按住可查看」。图两端的日期和卡片一样，写「11 月 8 日」。
- 28 日基线是一条虚线，图例也用虚线。纵轴大数用千分位。夜间 HRV 再加手表给的正常区间，图下写同一天的静息心率，不画进同一条轴。没有内容时不留空卡。睡眠时长的点按评分上色：85 分及以上、70–84、70 分以下。这组颜色只在图上，不进建议。
- 睡眠图下面是当晚的分期比例条（深睡、浅睡、REM、清醒的总分钟），加上入睡到起床的时段。这不是逐段时间轴。
- 静息心率升高时，折线用暖色。
- 恢复不画趋势。接口只有当天这一次。这一页放分数、档位、预计完全恢复，以及当晚的睡眠、HRV、静息心率。

## 运动

- 当天还没有记录、也没点过按钮：上方是建议。判断、处方一句、最多四条依据。标题只给结论，正文只给动作，缺什么、最近一条是哪天写在依据里。依据句式 `人话 —— 参照`。缺数据的那条排在最前。正文不把依据再贴一遍。依据里的「11 月 3 日」中间不断行，整段日期可以一起换到下一行。三个按钮在卡底，没选中不填橙色。
- 当天已有记录，或当天点过按钮：上方是这一次和结算卡，建议卡不出现。有记录时结算卡不放「重记一次」。点过按钮、记录还没来，留「重记一次」。细边框。约 150ms 淡入；系统开了「减少动态效果」就直接切。
- 建议或结算下面一行两张卡。本周是公里，周一到周日的柱从 0 起，没练的日子留空。当月是次数和日历，有记录的日子用蓝，月历从周一开始。点当月那张卡看今年十二个月。还没到的月份，以及这一年里第一条记录之前的月份，不写 0。从第一条记录所在的月份起，没练的月份写 0。页底不再重复本周三个数字。
- 已经放在页顶的当天记录，列表里不再出现一次。记录列表里，时长是每一行的锚点，放在左侧，写「49 分」「2 时 28 分」，不用冒号（「18:00」像钟点）。名字若整段只是英文运动类型（Run），显示成对应的中文；这时日期旁不再重复类型。有自己名字的记录仍写「11 月 7 日 · 跑步」。日期和趋势卡同一套。距离、配速或速度、心率、负荷降一级。骑车和徒步写速度。
- 单次详情仍是这一次里面的曲线：时长、距离、配速或速度、心率、已有分段。没有分段就不画。日期写「11 月 10 日」，后面是开始的时刻。没有爬升就不写单位。没有曲线时只说没有曲线。
- 运动能力页已有的体能曲线，补一句和 28 日基线的比较。基线算不出来就不写。
- 本周、本月和运动能力不进底栏。运动能力若在下一层出现，整行可点，不要再加一个「查看全部」。
- 橙色只给当前筛选项和当前 Tab。负荷数字和结算标题用正文色。环里的数字用 `font.lead`，本周公里和当月次数用 `font.metric`，今年的总次数用 `font.figure`。

改依据的说法可以动 `advice.ts` 的文案。改哪条分支命中，先问。

## 改界面时核对

- 打开第一眼是昨夜三项和各自的时间，不是那句剂量。
- 「睡眠与恢复」和「日常健康」里搜不到「可以上强度」「恢复良好，建议休息」。
- 建议只在「运动」里。缺了什么写在建议上。
- 触控不小于 48，按下有反馈，图标不是字符表情。
